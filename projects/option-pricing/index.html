Variance reduction for Monte Carlo option pricing

Problem. To price a European option by simulation with an error bar narrow enough to be useful, and to check the price against Black–Scholes.

stockdatamanager is a Python library I wrote before going to Aalto, for technical, fundamental and options analysis, with Greeks and option pricing by binomial trees and Crank–Nicolson. This page is its Monte Carlo counterpart.

Install it with pip install stockdatamanager.

What you are seeing

The red line is the running Monte Carlo estimate and the yellow band its 95% interval; the blue line is the Black–Scholes price. The band narrows like 1/√N in the number of paths N, so halving it takes four times as many. Variance reduction narrows it at almost no cost: antithetic draws pair each path with its mirror image, and a control variate subtracts the part of the payoff explained by the final stock price, whose mean is known. The paths stay the same as you move the sliders, so you can see how each input moves the price.

The American price comes from a 400-step binomial tree. For a put, its difference from the European price is the value of being able to exercise early.
