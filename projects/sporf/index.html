SPORF on current Python

A maintained fork of the SPORF random forest package that installs and runs on Python 3.8 to 3.14.

SPORF is a random forest that splits on sparse random linear combinations of features, where an ordinary forest splits on one feature at a time. Its Python package no longer builds on recent versions of Python and pip, and my fork makes it work again. I started it in May 2024 as a quick fix to get SPORF running on Colab, and brought it up to date properly in October 2026.

Sparse projection oblique randomer forests are due to Tomita and others.

What the fork changes

It restores the unsupervised forests, URF and URerF, and fixes a data race in the C++ code that updates their similarity matrix.

It removes an unused Eigen dependency and modernises the build, so the package installs with current pip on Python 3.8 to 3.14.

It makes scikit-learn 1.6 and later recognise the classifier, updates the tests for current scikit-learn, makes the unsupervised forests respect random_state, and adds continuous integration.

The changes are proposed upstream in neurodata/SPORF#361.
